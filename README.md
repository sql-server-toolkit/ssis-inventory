# 🇺🇸 English Version

## ❗ The Problem

If you work with SSIS in real-world environments, you already know:

- Packages are scattered  
- Hidden dependencies increase risk  
- SQL logic is hard to track  
- Documentation is outdated or missing  

---

## 💡 The Solution

SSIS Inventory analyzes `.dtsx` / `.ispac` files and extracts key metadata automatically.

---

## 🔍 What It Extracts

- Parameters  
- Variables  
- Connections  
- SQL Commands  
- Package Structure  

---

## 📊 Use Cases

- Environment Audit  
- Migration Preparation  
- Documentation  
- Maintenance  

---

## 🚀 Getting Started

```bash
python -m app.main --project-folder "<your_ssis_project>" --output-folder "./output"
```
