The problem

Many companies still depend on SSIS environments that are critical, complex and poorly documented. Before any change, migration or incident analysis, teams often need to manually inspect dozens or hundreds of packages.

Hidden dependencies

Connections, variables and embedded SQL logic are often spread across packages and hard to track.

Outdated documentation

Teams rely on tribal knowledge, spreadsheets or manual documentation that becomes obsolete quickly.

Migration risk

Moving to Azure, Microsoft Fabric or another platform is risky without a reliable inventory.

The solution

SSIS Inventory provides an automated way to scan SSIS projects and produce structured information that can support audits, maintenance, documentation and modernization initiatives.

What it extracts

  • Project and package structure
  • Parameters and variables
  • Connections and connection managers
  • Embedded SQL commands
  • Relevant metadata for analysis

How to run

python -m app.main --project-folder "<your_ssis_project>" --output-folder "./output"

Use cases

Use SSIS Inventory as a first step before technical decisions that require visibility into a legacy ETL environment.

Environment audit

Map what exists before planning improvements, refactoring or support actions.

Migration preparation

Identify dependencies and reduce uncertainty before moving workloads to modern platforms.

Documentation

Generate structured outputs that can be shared with technical teams, managers and stakeholders.
