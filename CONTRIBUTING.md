# 🇧🇷 Contribuindo (Português)

## 📌 Objetivo

Este projeto aceita contribuições que melhorem:

- Qualidade do parsing SSIS
- Clareza dos relatórios
- Governança entre ambientes (DEV/HOM/PRD)

---

## 🚀 Como contribuir

1. Faça um fork do repositório
2. Crie uma branch:

```bash
git checkout -b feature/minha-feature
```

3. Faça suas alterações
4. Adicione testes
5. Commit:

```bash
git commit -m "feat: descrição da melhoria"
```

6. Abra um Pull Request

---

## 📋 Boas práticas

- Funções pequenas e bem definidas
- Código legível
- Documentar regras de negócio
- Evitar duplicidade de lógica
- Garantir compatibilidade entre módulos

---

## 🧪 Testes

Execute:

```bash
pytest
```
